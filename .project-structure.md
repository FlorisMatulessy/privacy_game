# Project Organization

This file tracks the project structure organization.

## Directory Structure

### `/backend` - PHP Backend
All server-side PHP code is organized here:

- **`/backend/api/`** - All API endpoints (13 files)
  - Authentication: login.php, register.php, change_password.php
  - Settings: get_settings.php, update_settings.php
  - Departments: add_department.php, get_department_stats.php
  - Questions: add_question.php, update_question.php, delete_question.php, get_questions.php
  - Admin: admin_stats.php
  - Game: save_game_results.php

- **`/backend/helpers/`** - Shared utility functions
  - security_helpers.php (sanitization, validation, logging)

- **`/backend/setup/`** - One-time setup scripts
  - create_tables.php
  - add_email_to_db.php
  - fix_passwords.php
  - check_db.php

### `/src` - React Frontend
React components and application code (unchanged location).

### `/tests` - Testing & Security
All testing and security audit scripts:

- **`/tests/security/`** - Security testing tools
  - penetration_test.php - Real attack simulations
  - owasp_compliance_check.php - OWASP Top 10 verification
  - final_security_check.php - Automated security scan
  - security_audit.php - Database security audit
  - sql_injection_check.php - SQL injection vulnerability scanner
  - frontend_security_check.cjs - Frontend security analysis

### `/docs` - Documentation
All project documentation:
- SECURITY_PROOF.md - Complete security evidence
- SECURITY_AUDIT_REPORT.md - Detailed security audit
- EMAIL_SECURITY.md - Email validation documentation
- README.md - Original readme
- SECURITY.md - Security guidelines

### Root Directory
Only essential configuration and entry files:
- index.html - Entry point
- package.json - Dependencies
- vite.config.js - Build configuration
- tailwind.config.js - Styling configuration
- README.md - Project overview

## Path Updates

All import/require paths have been updated:

### Backend Files
```php
// Old: require_once 'security_helpers.php';
// New: require_once __DIR__ . '/../helpers/security_helpers.php';
```

### Frontend Files
```javascript
// Old: http://localhost/react-app/login.php
// New: http://localhost/react-app/backend/api/login.php
```

## Benefits

1. **Clear separation of concerns**: Backend, frontend, tests, docs
2. **Easier navigation**: Find files by category
3. **Better security**: Backend code isolated
4. **Maintainability**: Logical grouping of related files
5. **Professional structure**: Industry-standard organization
